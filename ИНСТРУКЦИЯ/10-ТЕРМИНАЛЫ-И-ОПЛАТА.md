# 💳 10 — Терминалы, карты и оплата (инструкция для персонала)

Это руководство — как **работать** во время мероприятия: принимать оплату,
выдавать карты, пополнять счёта. Техническая часть (запуск серверов) — в других
файлах; здесь только «что нажимать».

Всё происходит в браузере на адресе **`http://bank.lan`** (или по IP ноута A).

---

## 1. Из чего всё состоит (понятия)

| Понятие | Что это |
|---|---|
| **Счёт (аккаунт)** | Игрок или сотрудник. Роли: PLAYER (игрок), BANKER (кассир/банкир), ADMIN (организатор), DEVELOPER. |
| **Карта** | Физическая NFC-метка, привязанная к счёту игрока. По ней оплачивают. |
| **PIN** | Код, по которому игрок входит в систему (увидеть баланс, перевести). |
| **Валюты** | **Безналичные** (CASHLESS) и **Крипта** (CRYPTO). У каждого счёта два баланса. |
| **Терминал** | Запись о физической точке (касса, банкомат, ворота) — для учёта и статусов. |
| **Касса / POS** | Экран, где кассир принимает оплату по карте. |

**Кто что может (роли):**
- **PLAYER** — войти по PIN, посмотреть свой баланс/историю, перевести другому игроку (`Оплатить`), купить товар в магазине.
- **BANKER (кассир)** — всё для игрока + касса/POS, банкинг (пополнить/снять/перевести/отменить), карты, терминалы (просмотр), магазин, новости.
- **ADMIN** — всё вышеуказанное + создание счетов, выпуск PIN, управление терминалами, аналитика.

---

## 2. Оборудование кассы

- **Считыватель карт**: USB RFID-ридер (JT308, **125 кГц, формат EM4100**). Он
  работает как клавиатура — при поднесении карты «печатает» её номер и жмёт Enter.
  Драйверы не нужны.
- ⚠️ **Карты должны быть того же стандарта — 125 кГц EM4100.** Карты от метро/«Тройка»
  (13.56 МГц) этот ридер НЕ прочитает. Проверь совместимость при закупке.
- **Касса = любое устройство с браузером** (ноутбук/ПК), куда воткнут USB-ридер, и
  открыт `http://bank.lan`. Сам сервер на кассе не нужен — это просто клиент.
  > Телефоны/планшеты с USB-ридером обычно дружат плохо — для касс бери ноут/ПК.

**Проверка ридера:** открой Блокнот, приложи карту — должен впечататься номер
(8–10 цифр) и перейти на новую строку. Печатает → ридер работает.

---

## 3. Подготовка ДО мероприятия (делает ADMIN)

Войди как `admin` (или организатор) на `http://bank.lan`.

1. **Создать кассиров** (счета BANKER): «Счета → Создать», роль BANKER, задать пароль.
   Кассиры будут входить по имени+паролю.
2. **Создать счета игроков**: «Счета → Создать», роль PLAYER.
   (Массово удобнее — см. примечание в конце про `seed.mjs` для теста.)
3. **Выдать карты игрокам**: раздел **«Карты»** → приложить новую карту к ридеру
   (UID впечатается) → выбрать игрока → выпустить. Одна активная карта на игрока.
4. **Выдать PIN игрокам** (если игроки сами заходят в систему): «Счета → выбрать
   игрока → Выдать PIN». Один активный PIN на счёт.
5. **Начислить стартовый баланс**: «Банк → Пополнить» — выбрать игрока, валюту,
   сумму. (Или массово: «Банк → Массовое начисление».)
6. **Зарегистрировать терминалы**: «Терминалы → Зарегистрировать» — название
   (уникальное), тип (Касса/Банкомат/Ворота…), локация. Это для учёта точек.
7. **Завести товары** (если есть магазин): «Магазин → Товары» — название, цена,
   валюта, остаток.

## 4. 🧾 Принять оплату на кассе (главное)

Кассир (BANKER/ADMIN) открывает **«Касса / Терминал»** (`http://bank.lan/terminals/pos`).

### Вариант А. Списать произвольную сумму (за услугу, штраф, и т.п.)
1. Приложи карту игрока к ридеру → появятся **имя, роль, статус карты, балансы**.
2. Блок **«Списать средства»**: выбери валюту, введи сумму, при желании комментарий.
3. Нажми **«Списать»** → подтверди в окне.
4. Готово: покажет «Списано … Новый баланс …». Баланс на экране обновится.

### Вариант Б. Продать товар по карте
1. Приложи карту игрока.
2. Блок **«Купить товар по карте»**: выбери товар и количество — покажет сумму.
3. Нажми **«Оплатить картой»** → подтверди.
4. Готово: товар спишет нужную сумму с баланса игрока (с учётом остатка на складе).

> Если карта/счёт заблокированы — кнопки оплаты неактивны, сверху будет
> предупреждение. Что делать — см. раздел 7.

### Чек для игрока
После успешной оплаты (и списания, и покупки товара) на весь экран появляется
**чек «Оплачено»** с суммой, товаром и остатком. Поверни экран к игроку, чтобы он
увидел, что оплатил — операторская форма в этот момент скрыта. Нажми **«Готово»**,
чтобы закрыть чек и перейти к следующему клиенту.

## 5. Игрок платит сам (перевод другому игроку)

Игрок входит по PIN, открывает **«Оплатить / Перевести»** (`/me/pay`):
1. Приложить карту получателя к ридеру **или** ввести имя получателя вручную.
2. Выбрать валюту и сумму, нажать **«Оплатить»** → подтвердить.
3. Деньги уйдут с его счёта на счёт получателя (в пределах его баланса).

Это удобно для оплаты между игроками без участия кассира.

---

## 6. Банковские операции (BANKER/ADMIN, раздел «Банк»)

| Операция | Зачем | Где |
|---|---|---|
| **Пополнить** | Выдать игроку деньги | Банк → Пополнить |
| **Снять** | Забрать деньги со счёта | Банк → Снять |
| **Перевести** | Перекинуть между двумя счетами | Банк → Перевести |
| **Отменить** | Откатить ошибочную операцию | Банк → Отмена |
| **Массовое начисление** | Начислить всем сразу (событие) | Банк → Массовое начисление |
| **Баланс / История** | Посмотреть счёт и операции | Банк → Баланс / История |

> **Ошиблись при списании?** Не списывай «обратно» вручную — используй
> **«Банк → Отмена»** (reverse): найди операцию и откати, деньги вернутся корректно.
> Повторно отменить ту же операцию нельзя (защита от двойного возврата).

---

## 7. Карты: выпуск, блокировка, потеря, замена (раздел «Карты»)

| Ситуация | Что сделать |
|---|---|
| Новый игрок | Приложить карту → выбрать игрока → **Выпустить** |
| Карта потеряна | Найти карту игрока → **Потеряна (LOST)** → выдать новую → **Заменить** |
| Карту украли/блок | **Заблокировать (BLOCKED)** — оплата по ней перестанет работать |
| Узнать владельца | Приложить карту в кассе — покажет имя |

**Правила:** одна активная карта на игрока; номер карты (UID) уникален и
«занят» навсегда даже после блокировки; заблокированную/потерянную картой платить нельзя.

---

## 8. Терминалы: статусы (раздел «Терминалы»)

Реестр физических точек. ADMIN может менять статус:
- **ACTIVE** — работает.
- **MAINTENANCE** — на обслуживании.
- **BLOCKED** — заблокирован.
- **DECOMMISSIONED** — выведен из эксплуатации.

Название терминала после регистрации изменить нельзя; тип/локацию/заметку — можно
(кнопка «Изменить»). Это нужно для порядка и аудита, на саму оплату статус
терминала напрямую не влияет (оплата идёт через кассу по карте игрока).

## 9. Частые проблемы

| Симптом | Причина / решение |
|---|---|
| Карта не считывается | Не тот стандарт карты (нужен 125 кГц EM4100); ридер не в фокусе — кликни в поле «Считать карту»; проверь ридер в Блокноте. |
| «Карта не найдена» | Карта не привязана к игроку — выпусти её в разделе «Карты». |
| «Карта недоступна» | Карта BLOCKED/LOST — замени или разблокируй. |
| «Аккаунт заблокирован» | Счёт игрока BLOCKED — разблокируй в «Счета → статус». |
| «Недостаточно средств» | На балансе игрока не хватает выбранной валюты — пополни или уменьши сумму. |
| Ошибочно списал | «Банк → Отмена» — откати операцию (не списывай вручную обратно). |
| Игрок не может войти | Нет активного PIN или PIN отозван — выдай новый PIN. |
| Сайт не открывается | См. [05 — Если что-то сломалось](05-ЕСЛИ-ЧТО-ТО-СЛОМАЛОСЬ.md) и [09 — DNS](09-КРАСИВЫЙ-АДРЕС-DNS.md). |

## 10. Карта адресов (страниц)

| Раздел | Адрес | Кто |
|---|---|---|
| Касса / POS | `http://bank.lan/terminals/pos` | BANKER/ADMIN |
| Терминалы (реестр) | `http://bank.lan/terminals` | просмотр BANKER/ADMIN, управление ADMIN |
| Карты | `http://bank.lan/cards` | BANKER/ADMIN |
| Банк (операции) | `http://bank.lan/bank` | BANKER/ADMIN |
| Магазин (товары) | `http://bank.lan/market/products` | BANKER/ADMIN |
| Оплатить/перевести (игрок) | `http://bank.lan/me/pay` | любой вошедший |
| Мой баланс (игрок) | `http://bank.lan/me/balance` | любой вошедший |

> **Примечание про тестовые данные.** В папке `e2e` есть `seed.mjs` — генератор
> демо-данных для проверки (НЕ для боевого старта). Запускать только при тестах:
> `node e2e/seed.mjs`. Перед мероприятием база должна быть чистой (только admin) —
> при необходимости обнули: `deploy/balancer/reset-data.ps1 -Yes`.
