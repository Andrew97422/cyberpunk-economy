# ✅ 06 — Чеклист (распечатай и иди по нему)

## 0️⃣ Предусловия (дома, оба ноута)

- [ ] Свободно на диске: ноут A ≥ 25 ГБ, ноут B ≥ 15 ГБ.
- [ ] Docker Desktop запускается, `docker run --rm hello-world` работает.
- [ ] У Docker на ноуте B выделено ≥ 5 ГБ памяти (`docker info` → MemTotal;
      при нехватке — `.wslconfig`).
- [ ] Отключён сон и реакция на крышку (`powercfg`, см. [07](07-ЭКСПЛУАТАЦИЯ-И-ПИТАНИЕ.md)).
- [ ] Приостановлены обновления Windows / выставлен период активности.
- [ ] Включён автозапуск Docker Desktop при входе.
- [ ] Часы на обоих ноутах синхронны (сверить перед выездом).

## 🏠 Дома, пока есть интернет (ноут A)

- [ ] Docker Desktop установлен и запущен на ОБОИХ ноутах (`docker version`).
- [ ] Скачаны базовые образы: `docker pull postgres:16`, `docker pull apache/kafka:3.8.0`.
- [ ] (если нужен реестр) `docker pull registry:2`.
- [ ] Собраны образы проекта под `game-camp`:
      `docker compose -p game-camp -f docker-compose.yaml build`
- [ ] `docker images "game-camp-*"` показывает ~11 образов (вкл. analytics-service).
- [ ] (рекомендуется) Прогнал весь стек дома на одной машине — фронт открылся,
      админка пускает.
- [ ] Выгрузил образы: `.\deploy\balancer\export-images.ps1 -OutFile D:\camp-images.tar`.

## 📦 Перенос на ноут B (дома, по сети)

- [ ] Скопировал `camp-images.tar` на ноут B (SMB / реестр / SSH).
- [ ] Скопировал ПАПКУ проекта `D:\Лагерь июнь 2026` на ноут B.
- [ ] На ноуте B загрузил образы:
      `.\deploy\balancer\import-images.ps1 -InFile D:\camp-images.tar`.
- [ ] На ноуте B `docker images` показывает `game-camp-*` + базовые.

## 🌐 На месте — сеть

- [ ] Cudy AX3000 = главный, DHCP включён, задан SSID/пароль.
- [ ] Keenetic = расширитель, DHCP выключен, IP `192.168.1.2`, тот же SSID/пароль.
- [ ] Роутеры связаны (кабель + «Точка доступа» — лучше; либо WDS без кабеля).
- [ ] За ноутом A закреплён IP `192.168.1.10` (DHCP reservation на Cudy).
- [ ] Ноут A подключён к главному роутеру (желательно кабелем).
- [ ] На ноуте A открыты порты 80 и 53 (UDP+TCP) — брандмауэр, от админа. 9092/8080 — только для сплита.
- [ ] В `.env` `LAN_IP` = реальный IP ноута A.
- [ ] В DHCP роутера DNS-сервер = IP ноута A → работает `http://bank.lan` ([09](09-КРАСИВЫЙ-АДРЕС-DNS.md)).
- [ ] С ноута B проходит `ping 192.168.1.10`.

## 🚀 На месте — запуск (Primary + Standby, БЕЗ интернета, БЕЗ `-Build`)

- [ ] Ноут A: `docker compose -p game-camp -f docker-compose.yaml up -d`
- [ ] `docker compose -p game-camp ps` на A — контейнеры `running/healthy`.
- [ ] Ноут B: ничего не запускаем (горячий резерв), но он готов (образы + папка).
- [ ] С устройства открывается `http://bank.lan` (или `http://192.168.1.10`), админка пускает.
- [ ] `healthcheck.ps1 -EntryIp 192.168.1.10` — шлюз отвечает, токен получен.

## 🛡️ Отказоустойчивость

- [ ] На ОБОИХ ноутах есть все образы (без этого failover невозможен).
- [ ] Авто-бэкап на A включён (Планировщик, каждые 5–10 мин) с копией на B.
- [ ] Папка `Backups` на ноуте B расшарена (для `-PeerShare`).
- [ ] Failover отрепетирован дома: данные восстанавливаются ([08](08-ОТКАЗОУСТОЙЧИВОСТЬ.md)).
- [ ] Знаю, как отдать IP ноута A ноуту B при failover.

## 🔁 Каждый день

- [ ] Включить: сначала ноут A, потом ноут B (или просто дождаться автозапуска
      Docker Desktop — контейнеры поднимутся сами).
- [ ] Проверить `http://bank.lan` и вход в админку.
- [ ] Выключить: на каждом `docker compose -p game-camp down`
      (⚠️ НИКОГДА не добавляй `-v` — сотрёт все данные игры!).
- [ ] Оба ноута в розетке; ноут A не уснул и стабильно в сети.
