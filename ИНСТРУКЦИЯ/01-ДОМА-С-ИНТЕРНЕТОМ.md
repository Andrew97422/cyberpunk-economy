# 🏠 01 — Подготовка дома (пока есть интернет)

Это **самый важный** этап. Всё, что требует интернета, делается здесь и только
здесь. На месте интернета не будет — там уже ничего не скачать и не собрать.

Делается **на ноуте A** (16 ГБ, сильный). Ноут B трогаем в шаге переноса
([03 — Перенос образов](03-ПЕРЕНОС-ОБРАЗОВ.md)).

> Перед этим пройди [00 — Что нужно заранее](00-ЧТО-НУЖНО-ЗАРАНЕЕ.md) (диск,
> память Docker, виртуализация) и [07 — Эксплуатация и питание](07-ЭКСПЛУАТАЦИЯ-И-ПИТАНИЕ.md)
> (отключить сон/обновления — это тоже делается дома).

> Все команды — в **PowerShell**, запущенном из папки проекта
> `D:\Лагерь июнь 2026`. Открыть так: в Проводнике зайди в папку → в адресной
> строке набери `powershell` → Enter.

---

## Шаг 1. Установить и запустить Docker Desktop

На обоих ноутах должен стоять Docker Desktop и быть **запущен** (значок кита в трее).
На ноуте B он уже есть. На ноуте A — поставь, если ещё нет (нужен интернет).

Проверка:
```powershell
docker version
docker compose version
```
Обе команды должны показать версии без ошибок.

## Шаг 2. Скачать базовые образы

Это образы, которые проект не собирает, а берёт готовыми:
```powershell
docker pull postgres:16
docker pull apache/kafka:3.8.0
docker pull 4km3/dnsmasq:latest
```
(опционально, если захочешь веб-панель Kafka для отладки:)
```powershell
docker pull provectuslabs/kafka-ui:latest
```

## Шаг 3. Собрать образы проекта (ОДИН раз)

Собираем **все** сервисы под именем проекта `game-camp` из основного файла
`docker-compose.yaml` (конфигурация Primary+Standby) — это критично, чтобы потом
запуск нашёл готовые образы и не пытался собирать заново:

```powershell
docker compose -p game-camp -f docker-compose.yaml build
```

Это долго (качает зависимости Maven/npm, собирает все сервисы). Дождись конца.
Проверь, что образы появились:
```powershell
docker images "game-camp-*"
```
Должно быть ~11 строк (core, banking-service, account-service, access-service,
card-service, terminal-service, marketplace-service, news-service, audit-service,
analytics-service, frontend).

## Шаг 4. (Рекомендуется) Прогнать всё дома целиком

Пока есть интернет — убедись, что собранное вообще работает, на одной машине:
```powershell
docker compose -p game-camp-test -f docker-compose.yaml up -d --build
```
Открой `http://localhost`. Если фронт открылся и админка пускает
(логин и пароль — те, что ты задал в `.env`: `BOOTSTRAP_ADMIN_NAME` /
`BOOTSTRAP_ADMIN_PASSWORD`) — сборка живая. После проверки погаси тест:
```powershell
docker compose -p game-camp-test -f docker-compose.yaml down
```
> Это отдельный проект (`-p game-camp-test`), он не мешает образам `game-camp`.

## Шаг 5. Выгрузить образы в один файл

Чтобы перенести на ноут B:
```powershell
.\deploy\balancer\export-images.ps1 -OutFile D:\camp-images.tar
```
Получится файл ~1.5–2 ГБ (слои дедуплицируются). Это все образы (база + собранные). Дальше он уедет
на ноут B — см. **[03 — Перенос образов](03-ПЕРЕНОС-ОБРАЗОВ.md)**.

## Шаг 6. Проверить, что папка проекта готова к копированию

На ноут B поедет **вся папка** `D:\Лагерь июнь 2026` (compose-файлы, `.env`,
`deploy/`, `ИНСТРУКЦИЯ/`). Большой архив `бэк.zip` можно не копировать.
