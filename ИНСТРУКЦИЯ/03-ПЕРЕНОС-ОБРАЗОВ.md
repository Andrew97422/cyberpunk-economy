# 📦 03 — Перенос образов и папки проекта на ноут B

Образы переносятся **по сети** — интернет для этого НЕ нужен, нужна только
локальная сеть между двумя ноутами. Поэтому это можно сделать:
- **дома** по домашнему Wi-Fi (рекомендую — спокойно, без спешки), или
- **на месте** по закрытой сети (после настройки роутеров, см.
  [02 — Сеть и роутеры](02-СЕТЬ-И-РОУТЕРЫ.md)).

Нужно перенести **две вещи**: (1) файл образов `camp-images.tar` и (2) папку
проекта `D:\Лагерь июнь 2026`.

Ниже три способа. **Начни со Способа 1** — он самый простой. Если не получится —
переходи к следующему.

---

## Способ 1. Общая папка по сети (SMB) — рекомендую

Самый привычный: «расшарить» папку на ноуте A и скопировать с ноута B как обычный файл.

**На ноуте A:**
1. Положи `camp-images.tar` и папку проекта в одну папку, например `D:\Share`.
2. Правый клик по папке → **Свойства → Доступ → Общий доступ** → добавь
   пользователя `Все` (Everyone) с правом «Чтение» → **Поделиться**.
3. Запомни имя ноута A: `hostname` в PowerShell (или используй его IP).

**На ноуте B (Проводник):**
1. В адресной строке Проводника набери `\\<имя-или-IP-ноута-A>\Share` → Enter.
   Если спросит логин/пароль — введи учётку пользователя ноута A.
2. Скопируй `camp-images.tar` и папку проекта к себе, например в `D:\Лагерь июнь 2026`.

**Загрузить образы (на ноуте B):**
```powershell
cd "D:\Лагерь июнь 2026"
.\deploy\balancer\import-images.ps1 -InFile D:\camp-images.tar
```

> Если SMB не находит ноут (сеть «Общедоступная»): на обоих ноутах
> Параметры → Сеть → выбери профиль сети **«Частная»**, включи «Сетевое
> обнаружение». Либо используй IP вместо имени: `\\192.168.1.10\Share`.

---

## Способ 2. Локальный Docker Registry (если будешь часто обновлять)

Образы передаются прямо через Docker по сети. Удобно, если планируешь
пересобирать и обновлять не раз. Интернет не нужен.

**На ноуте A** (поднять реестр):
```powershell
docker run -d -p 5000:5000 --restart=unless-stopped --name registry registry:2
```
> Образ `registry:2` тоже скачай дома заранее: `docker pull registry:2`.

Перетегировать и залить образы (подставь IP ноута A вместо `192.168.1.10`):
```powershell
$A = "192.168.1.10:5000"
docker images "game-camp-*" --format "{{.Repository}}:{{.Tag}}" | ForEach-Object {
  $name = ($_ -split ":")[0]
  docker tag $_ "$A/$name"
  docker push "$A/$name"
}
docker tag postgres:16 "$A/postgres:16"; docker push "$A/postgres:16"
docker tag apache/kafka:3.8.0 "$A/kafka:3.8.0"; docker push "$A/kafka:3.8.0"
```

**На обоих ноутах** разрешить HTTP-реестр: Docker Desktop → Settings →
**Docker Engine** → в JSON добавь строку и нажми Apply & Restart:
```json
"insecure-registries": ["192.168.1.10:5000"]
```

**На ноуте B** скачать из реестра — но проще оставить Способ 1 для образов,
а реестр использовать только если реально нужны частые обновления. Для разового
мероприятия Способ 1 надёжнее и понятнее.

---

## Способ 3. По SSH одной командой (для любителей терминала)

Без промежуточного файла, но на ноуте B надо включить **OpenSSH Server**
(Параметры → Приложения → Доп. компоненты → «OpenSSH Server» → запустить службу).

С ноута A:
```powershell
docker save (docker images "game-camp-*" --format "{{.Repository}}:{{.Tag}}") postgres:16 apache/kafka:3.8.0 | ssh user@192.168.1.11 "docker load"
```
Папку проекта всё равно придётся скопировать отдельно (Способ 1).

---

## После переноса: проверка на ноуте B

```powershell
docker images
```
Должны быть видны `game-camp-*`, `postgres:16`, `apache/kafka:3.8.0`. Если есть —
ноут B готов, собирать ему ничего не придётся.
