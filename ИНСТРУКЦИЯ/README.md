# 📋 Инструкция по развёртыванию (лагерь, закрытая сеть)

Это главный файл. Читай сверху вниз, переходи по ссылкам. Все детали вынесены
в отдельные файлы рядом.

## Что у нас есть

- **Ноут A — «основной» (Primary), 16 ГБ** (этот, сильный). На нём крутится весь
  стек, к нему подключаются все устройства. Здесь же собираются образы.
- **Ноут B — «резерв» (Standby), 8 ГБ** (только Docker Desktop). В норме простаивает;
  имеет все образы и свежие бэкапы, чтобы подхватить, если ноут A откажет.
- **Два роутера**: Cudy AX3000 (главный) + Keenetic KN-1610 (расширитель покрытия).
- **Интернета на месте НЕ будет.** USB-переноса тоже нет — всё по сети.

## Главный принцип (запомни)

- **Интернет нужен ТОЛЬКО для сборки образов.** Сборка — один раз, дома.
- **Перенос образов по сети интернета НЕ требует** — нужна лишь локалка между ноутами.
- Поэтому: собираем и готовим всё дома, на месте — только включаем.

## Конфигурация: Primary + Standby (выбрана ради отказоустойчивости)

| Ноут | Роль | Что делает |
|------|------|-----------|
| **A (16 ГБ)** | Primary | Крутит **весь стек** (`docker-compose.yaml`): Postgres, Kafka, шлюз, фронтенд, все сервисы |
| **B (8 ГБ)** | Standby (резерв) | В норме простаивает; имеет все образы и свежие бэкапы; подхватывает, если A умрёт |

Устройства игроков заходят на **`http://bank.lan`** (или `http://<IP_ноута_A>`).
Настройка красивого имени — [09 — Красивый адрес (DNS)](09-КРАСИВЫЙ-АДРЕС-DNS.md). Подробнее, почему так
надёжнее, и план failover — [08 — Отказоустойчивость](08-ОТКАЗОУСТОЙЧИВОСТЬ.md).

> Альтернатива — сплит по двум ноутам (балансировщик `balance.ps1`), если важнее
> делить нагрузку. Минус: две точки отказа и нет аналитики. См. [04](04-ЗАПУСК-НА-МЕСТЕ.md), Вариант 2.

---

> ⚠️ **Адреса вида `192.168.1.x` во всех файлах — это ПРИМЕР.** Реальная подсеть
> зависит от твоего роутера и может быть другой. Как узнать свою — см.
> [02A — Как узнать IP](02A-КАК-УЗНАТЬ-IP.md), и подставляй свои числа везде.

## Где что лежит

- Запуск всего стека: `СТАРТ.cmd` (или `deploy/balancer/start-all.ps1`).
- Основной конфиг (Primary+Standby): `docker-compose.yaml` + `.env`.
- Скрипты: `deploy/balancer/` (start-all, reset-data, backup/restore, healthcheck,
  export/import образов, а также balance.ps1 для альтернативного сплита).
- Конфиги сплита (альтернатива): `compose.core.yaml`, `compose.finance.yaml`, `compose.rest.yaml`.
- Эти инструкции: папка `ИНСТРУКЦИЯ/`.
